# Contributing

Issues and pull requests are welcome. Fork this repository, install dependencies with `npm ci`, make your change, and run the checks in [README.md](README.md). Include a reproduction or regression test for bug fixes. Keep keys, account data and local configuration out of commits.

Maintainers also apply accepted changes to the canonical Revdoku source before releases. Source and contributions use the [MIT license](LICENSE). Support: support@revdoku.com.
